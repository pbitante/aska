---
name: user-value
description: Does this make a real, noticeable difference to users soon?
threshold: medium
---

## Looks for
Who benefits, how much, and how soon, and whether users will notice. How quickly it can ship is delivery-speed's concern; whether every user can operate it is accessibility-ux's.

## Questions
- Which user problem does this solve, and how do we know it matters?
- How soon does a user feel the benefit?
- How will we see whether it worked?

## Red flags
- No user-facing outcome can be named
- The value depends on a later change that is not planned
- No way to tell after release whether it helped

## Good looks like
A named user problem, solved in this change, with a way to see that it worked.
