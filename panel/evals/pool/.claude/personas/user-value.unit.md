---
name: user-value
description: Does this make a real, noticeable difference to users soon?
threshold: medium
---

## Looks for
Who benefits, how much, and how soon; whether users will notice.

## Questions
- Which user problem does this solve, and how do we know it matters?
- How soon does a user feel the benefit?

## Red flags
- No user-facing outcome can be named
- Value depends on a later change that is not planned

## Good looks like
A named user problem, solved in this change, with a way to see that it worked.
